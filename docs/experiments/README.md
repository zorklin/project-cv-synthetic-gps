# Height experiment history

These reports describe how the optional height correction was developed. They
are historical research records, not steps in the supported pipeline.

| Report | Stage | Outcome |
|---|---|---|
| [Barometer bias](height-bias.md) | Initial diagnosis and speed-aware bias | Promising full-flight improvement, with late over-correction |
| [Mean reversion and output smoothing](height-reversion.md) | Follow-up correction | Better full-flight result, still requiring temporal validation |

The subsequent validation decisions are documented under
[`docs/results/`](../results/README.md).
